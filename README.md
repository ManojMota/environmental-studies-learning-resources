# Environmental Studies – Learning Resources

Open educational resources for Environmental Studies, prepared for undergraduate engineering learners.

This repository brings together module-wise presentations and will progressively include lecture notes, case studies, datasets, practical exercises and additional references.

## How to use these resources

- Open a module folder to access its presentations.
- Download a PowerPoint file to view or use it for learning.
- Additional PDF versions, datasets, assignments and case studies may be added as they become available.
- Please check the individual module README files for a short description of each module.

## Repository scope

The presentations in this repository are organised according to the supplied Environmental Studies course material. Specialised topics such as SDGs, Life Cycle Assessment, Environmental Impact Assessment, air pollution, water treatment and solid waste management may also be developed further in dedicated repositories. Where appropriate, those repositories can be cross-linked rather than duplicating the same learning material.
